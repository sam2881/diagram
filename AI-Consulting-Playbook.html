8 Formulas & Methodology

Comprehensive documentation of all calculations, scoring models, and financial methodologies used in this playbook for transparency and auditability.

Return on Investment (ROI)

Measures the efficiency of an investment

ROI % = ((Net Benefits - Total Investment) / Total Investment) x 100

Components:

  • Net Benefits = Labor Savings + Error Reduction + Revenue Uplift + Cycle Time Savings
  • Labor Savings = Hours Saved x Hourly Rate x Burden Rate (typically 1.3x for benefits)
  • Total Investment = CAPEX + OPEX + Training & Change Management

Interpretation: ROI > 100% indicates the investment has doubled in value. For AI projects, target ROI should exceed the organization's hurdle rate (typically 15-25%).

Net Present Value (NPV)

The present value of future cash flows minus initial investment

NPV = -Initial Investment + Sum of [Cash Flow(t) / (1 + r)^t]

Where:

  • Cash Flow(t) = Net benefit in period t (Benefits - OPEX) adjusted for adoption ramp
  • r = Discount rate (WACC + Risk Premium, typically 10-15%)
  • t = Time period (years)

Decision Rule: Accept project if NPV > 0. Higher NPV is preferred when comparing projects.

Internal Rate of Return (IRR)

The discount rate that makes NPV equal to zero

0 = -Initial Investment + Sum of [Cash Flow(t) / (1 + IRR)^t]

Calculation Method: Solved iteratively (Newton-Raphson method) as there is no closed-form solution.

Decision Rule: Accept if IRR > WACC (Weighted Average Cost of Capital). For AI projects, IRR > 25% is typically considered excellent.

Benchmarks:

  • < 10%: Below typical corporate hurdle rate
  • 10-20%: Acceptable
  • 20-40%: Good
  • > 40%: Excellent

Payback Period

Time required to recover the initial investment

Payback (months) = (Total Investment / Annual Net Benefit) x 12

With Adoption Ramp: Calculated by finding the point where cumulative cash flow turns positive.

Benchmarks for AI Projects:

  • < 6 months: Ideal for pilot projects
  • 6-12 months: Acceptable for departmental initiatives
  • 12-24 months: Standard for enterprise implementations
  • > 24 months: Requires strong strategic justification

Weighted Average Cost of Capital (WACC)

Minimum return required on investments

WACC = (E/V x Re) + (D/V x Rd x (1-Tc))

Where:

  • E = Market value of equity
  • D = Market value of debt
  • V = E + D (Total firm value)
  • Re = Cost of equity
  • Rd = Cost of debt
  • Tc = Corporate tax rate

Simplified: For AI project evaluation, use company's stated hurdle rate (typically 8-15%) plus a technology risk premium (2-5%).

Weighted Priority Score

Multi-criteria decision analysis for use case prioritization

Priority Score = Sum of (Criterion(i) x Weight(i)) for all criteria

Default Criteria Weights:

Feasibility20%1-5Higher is better

Data Readiness15%1-5Higher is better

Score Interpretation:

  • Score > 3.5: High Priority
  • Score 2.0-3.5: Medium Priority
  • Score < 2.0: Low Priority

RICE Scoring Model

Alternative prioritization framework (Reach, Impact, Confidence, Effort)

RICE Score = (Reach x Impact x Confidence) / Effort

Components:

  • Reach: Number of users/transactions affected per quarter (e.g., 1000 users)
  • Impact: Effect on each user (3=Massive, 2=High, 1=Medium, 0.5=Low, 0.25=Minimal)
  • Confidence: Certainty of estimates (100%=High, 80%=Medium, 50%=Low)
  • Effort: Person-months required (e.g., 2 = two person-months)

Example: (5000 x 2 x 0.8) / 3 = 2,667 RICE score

Value vs. Complexity Matrix

Portfolio visualization framework

X-Axis = (Feasibility + (5 - Time to Value)) / 2
Y-Axis = (Business Value + (5 - Cost)) / 2

Quadrant Interpretation:

  • Top-Right (High Value, High Feasibility): Quick Wins - Implement first
  • Top-Left (High Value, Low Feasibility): Strategic Initiatives - Plan carefully
  • Bottom-Right (Low Value, High Feasibility): Fill-ins - Implement if resources allow
  • Bottom-Left (Low Value, Low Feasibility): Deprioritize - Avoid or defer

Total Cost of Ownership (TCO)

Comprehensive cost framework for AI initiatives

TCO = Initial Costs + Sum of (Operating Costs(t) / (1 + r)^t) + Hidden Costs

Cost Categories:

CategoryComponentsTypical % of Total
InfrastructureGPU compute, storage, bandwidth, cloud services20-35%
Data PreparationLabeling, cleaning, sourcing, ETL pipelines30-50%
PersonnelData scientists, ML engineers, PMs25-40%
IntegrationAPI development, legacy system connections15-25%
Security & ComplianceAudits, red teaming, bias testing5-15%
Training & ChangeUser training, documentation, adoption10-20%

Warning: 85% of organizations underestimate AI project costs by >10%. Always include a contingency buffer of 20-30%.

Ongoing Operational Costs

Recurring costs after initial deployment

Annual OPEX = Compute + Storage + Licenses + Maintenance + Retraining

Key Considerations:

  • Model Drift: 91% of ML models experience degradation over time, requiring retraining (15-25% additional compute)
  • API Costs: For LLM-based solutions, estimate monthly token usage (e.g., 500K calls x $0.02 = $10K/month)
  • Scaling: AI infrastructure costs scale non-linearly with usage
  • Monitoring: Continuous monitoring tools and personnel (typically 10-15% of development cost annually)

Scenario Analysis

Testing outcomes under different assumptions

Best Case: Benefits x 1.3, Costs x 0.9
Likely Case: Base estimates
Worst Case: Benefits x 0.7, Costs x 1.2

Methodology:

  • Best Case (+30% benefits, -10% costs): Optimistic scenario with faster adoption, higher savings
  • Likely Case: Base estimates from assessment
  • Worst Case (-30% benefits, +20% costs): Conservative scenario with delays, overruns

Decision Framework: Project should show positive NPV even in worst case scenario for low-risk approval.

Break-Even Analysis

Finding the point where benefits equal costs

Break-Even Volume = Fixed Costs / (Benefit per Unit - Variable Cost per Unit)

For AI Projects:

  • Break-Even Adoption Rate: Minimum adoption % needed to achieve positive ROI
  • Break-Even Time: Number of months until cumulative benefits exceed cumulative costs
  • Break-Even Efficiency: Minimum efficiency gain (%) required for positive business case

Sensitivity Variables

Key variables to test in sensitivity analysis

High-Impact Variables (test +/- 20-30%):

  • Adoption rate / utilization
  • Hourly rate / labor cost
  • Hours saved / efficiency gain
  • Implementation timeline

Medium-Impact Variables (test +/- 10-20%):

  • Discount rate
  • OPEX / recurring costs
  • Training costs

Sensitivity Ratio: % change in NPV / % change in variable. Variables with ratio > 1 are "high sensitivity" and require careful estimation.
