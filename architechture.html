📡 Protocol Layers

Kafka (External) A2A (Agents) MCP (Tools) REST/Webhooks
NEW→ RECEIVED→ ENRICHED→ JUDGED→ PLAN_GEN→ APPROVED→ EXECUTED→ VERIFIED→ CLOSED | FAILED→ ROLLBACK→ MANUAL

📨 Kafka (External)

  • ServiceNow integration
  • State transitions (audit)
  • Replay capability
  • Schema evolution
  • Cross-system events
  • Compliance trail

🤝 A2A (Agents)

  • Agent-to-Agent real-time
  • Swarm coordination
  • Judge evaluation requests
  • Agent discovery
  • Capability negotiation
  • Low latency messaging

🔧 MCP (Tools)

  • Agent → Tool invocation
  • JSON-RPC 2.0 protocol
  • RAG queries/updates
  • ServiceNow operations
  • GitHub tool calls
  • Terraform/Ansible tools

🌐 REST/Webhooks

  • GitHub Actions trigger
  • workflow_dispatch API
  • Jira integration
  • Slack/Teams webhooks
  • PagerDuty API
  • External API calls

🐝 Swarm RAG

  • A2A: Agent consensus
  • MCP: Tool queries
  • Find best .tf/.yml
  • Rank by success rate
  • Avoid blast radius
  • Learn from outcomes

🔧 Resolution Flow

  • Swarm finds script (A2A)
  • Agent gets .tf/.yml (MCP)
  • Trigger GH Action (REST)
  • Terraform apply / Ansible
  • Verify outcome (Kafka)
  • Update RAG (MCP)
