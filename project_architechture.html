1. Platform Overview

An enterprise-grade AI-powered incident management platform that automates the detection, classification, and remediation of IT infrastructure incidents. The platform integrates with ServiceNow for ticket management, uses hybrid RAG for intelligent script matching, and executes remediation through GitHub Actions.

Key Capabilities

50+ Automated Scripts
95% Classification Accuracy
<5s Analysis Time
14 Workflow Nodes

Technology Stack

  • Backend: FastAPI (Python 3.12), LangGraph, OpenAI GPT-4
  • Frontend: Next.js 14, React Query, TailwindCSS
  • Databases: Weaviate (Vector), Neo4j (Graph), PostgreSQL, Redis
  • Streaming: Apache Kafka (incident events)
  • Execution: GitHub Actions (remediation scripts)
  • Integration: ServiceNow (ITSM), Slack (approvals)

4. RAG System & Formulas

Hybrid Search Architecture

Vector Search (Weaviate)

Semantic similarity using OpenAI embeddings (text-embedding-3-small)

backend/rag/embedding_service.py
vector_score = cosine_similarity(query_embedding, script_embedding)

Graph Search (Neo4j)

Knowledge graph with FIXED_BY relationships and success rates

backend/rag/neo4j_client.py
graph_score = (success_rate * 0.6) + (execution_count * 0.3) + (recency * 0.1)

Keyword Search (BM25)

Traditional keyword matching with TF-IDF scoring

backend/rag/hybrid_search_engine.py
bm25_score = sum(idf(term) * tf(term, doc) * (k1 + 1) / (tf + k1))

Final Score Calculation

Hybrid Score Formula:

final_score = (vector_weight * vector_score) + (graph_weight * graph_score) + (keyword_weight * keyword_score) + (metadata_boost)

Default Weights:
- vector_weight = 0.4 (semantic similarity)
- graph_weight = 0.35 (historical success)
- keyword_weight = 0.25 (keyword overlap)
- metadata_boost = 0.1 (category/service match)

Swarm Script Selector

Multi-agent evaluation system using specialized agents:

Agent Weight Evaluation Criteria
SemanticAgent40%Keyword/pattern match, vector score
SafetyAgent35%Risk level, blast radius, rollback availability
ContextAgent25%Historical patterns, graph relationships
ConsensusAgent-Aggregates weighted scores, makes final decision

Consensus Decision Formula

final_score = sum(agent_score * agent_weight * agent_confidence) / sum(agent_weight * agent_confidence)

Auto-approve if: final_score >= 0.5 AND risk_level in ['low', 'medium'] AND no_approval_flags

11. Incident Resolution Lifecycle

End-to-End Flow Example: "GCP VM is down"

  1. Detection: ServiceNow ticket created "test-vm-01 is terminated"
  2. Ingestion: Kafka consumer picks up from servicenow.incidents topic
  3. Classification: LLM classifies as "infrastructure/gcp"
  4. RAG Search: Swarm agents search for matching scripts
    • Vector: 0.92 match to "Start GCP Instance"
    • Graph: 8 historical successes for VM start
    • Keywords: "terminated", "vm", "gcp" matched
  5. Plan Generation: LLM creates 3-step plan
    • Step 1: Validate VM exists
    • Step 2: Execute start_gcp_instance.sh
    • Step 3: Verify VM is running
  6. Judge Evaluation: Quality: 8.5, Safety: PASS, Feasibility: 7.5
  7. Control Plane: Risk: MEDIUM, Route: async_approve
  8. Approval: Slack notification sent, user approves
  9. Execution: GitHub Actions shell-execute.yml triggered
  10. Verification: VM status checked, confirmed RUNNING
  11. Closure: ServiceNow ticket updated to "Resolved"
  12. Feedback: Neo4j updated with FIXED_BY relationship
